# Reporting Views

The system provides multiple views and reports to aid in monitoring and evaluation.

## Types of Reports

### 1. **Fund Utilization Report**
- Aggregates planned vs. actual spending per project, district, and month.
- Available under: `Reports > Fund Utilization`

### 2. **Activity Status Summary**
- Shows the count of activities in each status (Draft, Submitted, Approved).
- Filters: Project, District, Date Range

### 3. **Planning Sheet Summary**
- View all submitted Planning Sheets with approval status.
- Helps identify districts pending submission.

## Export Options

- All reports can be exported to Excel/CSV using built-in Frappe export tools.
- Charts are viewable inline and downloadable as PNG/SVG.

## Access Control

- Each role can only see reports relevant to their scope (e.g., DCs see only their district).
