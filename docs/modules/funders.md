# Funders Module

The Funders module captures key information about all donor organizations and their points of contact.

---

## Fields

| Field | Description |
|-------|-------------|
| **Funder Name** | Name of the organization funding the project |
| **Funder Type** | Government, NGO, Private, etc. |
| **Funder Status** | Active / Inactive |
| **Funder ID** | Unique ID auto-generated |
| **Point of Contact (POC)** | Name of the primary contact person |
| **POC Phone** | Mobile number of the POC |
| **POC Email** | Email address of the POC |
| **Preferred Communication** | Email / Phone / WhatsApp |
| **POC Designation** | Title or position of the POC |
| **Government ID** | PAN Card or Aadhaar (mandatory field) |

---

## 📝 User Instructions

### ✅ To Create a New Funder:
1. Navigate to the **Funders** module.
2. Click on **New**.
3. Fill all required fields: Funder Name, Type, POC details, etc.
4. Upload PAN or Aadhaar card, based on `gov_id` selection.
5. Click **Save** and then **Submit** (if applicable).

### 🔍 To View/Edit an Existing Funder:
1. Use the search bar or filter options.
2. Click on the row to open the funder record.
3. Click **Edit** to update details.
4. Save changes. Submissions may go through a validation process.

---

## 🛠 Tips

- Ensure valid contact details to enable alerts.
- Funders must be linked to Projects during Project creation.
- Use filters by Funder Type or Status for quick navigation.
