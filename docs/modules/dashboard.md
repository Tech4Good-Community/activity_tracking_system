# Dashboard Module

The dashboard is the central overview panel available primarily to Senior Management and State/City Managers. It displays visual summaries and number cards for both financial and non-financial activities.

---

## 📊 Key Metrics Displayed

### For the Current Month:
- Number of Financial Activities
- Number of Non-Financial Activities
- Number of Financial Activities Due (Payment not processed)
- Number of Non-Financial Activities Due
- Number of Non-Financial Activities Overdue (from last month)
- Number of Financial Activities Completed On Time
- Number of Non-Financial Activities Completed On Time

### Year-to-Date:
- Percentage of Financial Activities Completed
- Percentage of Non-Financial Activities Completed

### Budget Overview:
- Actual Budget Allocated
- Actual Budget Utilized
- % Budget Utilized

---

## 📝 User Instructions

### ✅ To View the Dashboard:
1. Login to the system with appropriate role.
2. Navigate to **Dashboard** from the sidebar or Home page.
3. Use filters to view data by:
   - City
   - Project
   - Department
   - Financial / Non-Financial activity

---

## 🔔 Notes

- Data on the dashboard auto-refreshes daily or on trigger.
- Pending activities are clickable and can redirect to their detail pages.
- Escalations and alerts are shown at the top for attention.
