# Reports Module

The Reports module allows role-based access to detailed data on activities, budgets, and statuses. Each role sees relevant filters and fields.

---

## 🧑‍💼 State Manager Report

Includes all City Manager fields, plus:
- Approval by Chief of Party

---

## 📋 Director Program View

Same as above, includes:
- Activity Approval Status (overall)
- Comments from all approvers

## 🛍 Procurement Department View

Includes:
- Procurement milestones:
  - Request Raised
  - Scope ID Created
  - Best Bid Selected

  - Invoice & Payment Status

## 🧑‍💼 HR and Admin Department View

Includes:
- Recruitment milestones:
  - JD Prepared
  - Job Advertised
  - Candidates Shortlisted

  - Job Offer
  - Candidate Joined

---

## 💵 Finance Department View

Same as City Manager, with focus on:
- Budget Utilization
- Final Payment Status
- Comments for validation

---

## 📝 User Instructions

### ✅ To Access a Report:
1. Go to **Reports** > Choose your department or role.
2. Apply filters such as City, Project, Activity Type.
3. Click on any row to see the underlying record.
4. Export using the **Export** button (Excel or CSV).

---

## 🛠 Notes

- Reports are dynamically filtered by user roles.
- Some reports may be restricted for viewing only (e.g. Director-level).
