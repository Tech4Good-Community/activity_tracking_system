# PSI Activity Tracking System – User Manual

Welcome to the user manual for the PSI Activity Tracking System, built on the Frappe framework. This system helps manage planning, activity tracking, fund allocation, and reporting across PSI’s programs and teams.

## Key Modules Covered

- Funders and Projects
- Activity Planning and Tracking
- Fund Allocation
- Role-based Approval Workflows
- Dashboards and Reports
- Automated Notifications
- Technical Configuration

## Who Should Use This Manual

This guide is structured for:
- Program Implementation Teams
- Finance, Procurement, and HR Departments
- City and State Managers
- Data Entry Operators, Validators, and Analysts
- Senior Management

## How to Use This Manual

Each module or functionality is explained in a separate Markdown file:
- Go to the `modules/` folder for data entry and tracking guides
- Visit the `workflows/` folder to understand approval flows
- Refer to `roles-and-access.md` for access privileges
- Use `system-admin.md` for backend management and troubleshooting

---
For questions, contact the PSI IT Support Team or your assigned Data Manager.
