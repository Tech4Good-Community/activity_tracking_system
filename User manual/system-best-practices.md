# System Usage Best Practices (For Users)

This guide is meant for general users of a PSI system. It highlights good practices to follow while using the system to ensure smooth operations, clean data, and minimal errors.

---

## 1. DATA ENTRY

- **Be Consistent:** Use the same format when entering names, dates, addresses, etc.
- **Avoid Typos:** Double-check spelling, especially in key fields like names, IDs, and numbers.
- **Fill All Required Fields:** The system may allow saving with missing data — but always try to complete all important details.

---

## 2. NAVIGATION

- **Use the Global Search:** If you don’t remember where something is, try searching at the top bar.
- **Use the Sidebar:** Most modules (Planning, Tracking, Reports, etc.) are listed in the left sidebar for easy access.
- **Open in New Tabs:** Right-click and open items in new tabs if you’re comparing or referencing multiple records.

---

## 3. SAVING & SUBMITTING

- **Save First:** If you're filling a long form, save regularly to avoid losing work.
- **Submit Only When Final:** Submitting locks the record. Only do this when you're sure the information is correct.
- **Edit Carefully:** If editing a submitted document, make sure you’re authorized and understand the impact.

---

## 4. USING FILTERS & REPORTS

- **Use List Filters:** On list views, use filters to find records quickly by date, name, status, etc.
- **Export Data (if allowed):** Most reports allow exporting to Excel — use this for analysis, not for making changes.
- **Don’t Modify Default Reports:** Create a new report version if you need a customized view.

---

## 5. ATTACHMENTS & NOTES

- **Use Attachments Wisely:** Upload clear and relevant files (e.g., photos, PDFs).
- **Add Notes When Needed:** Use the Notes section to clarify changes, exceptions, or history.

---

## 6. WORKFLOWS & APPROVALS

- **Know the Flow:** Understand what happens after you create a record — does it go to someone for approval?
- **Follow Up:** Use comments or emails inside the system to tag and notify the right people.
- **Don’t Bypass Steps:** Always follow the set workflow (e.g., draft → review → submit).

---

## 7. USER ACCOUNTS

- **Keep Your Password Safe:** Never share your login with others. Change it regularly.
- **Log Out When Done:** Especially important if using a shared or public computer.
- **One User = One Person:** Avoid shared accounts. It makes tracking actions difficult.

---

## 8. TROUBLESHOOTING

- **Something Not Working?**
  - Try refreshing the page.
  - Check if the internet is stable.
  - Clear browser cache if things look broken.

- **Still Stuck?**
  - Report the issue clearly: what you were doing, what you expected, and what went wrong.
  - Share screenshots if possible.

---

## 9. DOs AND DON'Ts

**✅ DO:**
- Enter complete and clean data.
- Ask if unsure about a feature.
- Report bugs and errors clearly.
- Use comments to communicate within a record.

**❌ DON’T:**
- Delete important records unless you’re sure.
- Use dummy or test data in production.
- Share your login or password.
- Change workflows without informing your team.

---

## 10. SUPPORT & FEEDBACK

- If you face regular issues, contact your admin or support team.
- Suggest improvements — the system is made better with user feedback.

---

**Thank you for using the system responsibly!**
