# Notifications

The system uses notifications to alert users of key events and approvals required.

## Notification Types

| Trigger | Recipient | Description |
|--------|-----------|-------------|
| Fund Allocation Submitted | State Coordinator | Notification to review and approve the fund allocation |
| Activity Submitted | District Coordinator / State Coordinator | Notification to review activity and send feedback |
| Planning Sheet Submitted | State Coordinator | Notification to approve or reject |
| Fund Allocation Rejected | District Coordinator | Informs DC to revise fund allocation |
| Activity Approved | DC and Field Staff | Indicates activity can be initiated |

## Delivery Method

All notifications appear within the system's notification bell

## Customization

Admins can customize notification templates in the "Notification" DocType under the "Automation" module.
