# User Roles and Access Levels

The PSI Activity Tracking System supports a detailed role-based access structure.

---

## 🛡️ Access by Role Hierarchy

| Role | Access Scope |
|------|--------------|
| **Senior Management** | All cities, states, and projects |
| **Chief of Party / Director – Program** | Their respective projects only |
| **Deputy Director (Program/DCOP)** | Their respective projects only |
| **State Manager / General Manager – Program Implementation** | Their respective states and projects |
| **City Manager / Manager – Program Implementation** | Their respective cities, states, and projects |

---

## 👥 Activity Tracking Roles

| Role | Function |
|------|----------|
| Super Admin | Full access to all modules and settings |
| Admin | High-level access with config permissions |
| Data Manager | Verifies and manages submitted data |
| Data Validator | Validates input from data operators |
| Data Entry Operator | Adds and edits daily operational data |
| Data Analyst | Analyzes data and supports reporting |
| Reporting Specialist | Prepares and publishes reports |

---

## 🏢 Departmental Roles

Includes department-specific access for:
- Finance
- HR and Administration
- Procurement
- MLE (Monitoring, Learning & Evaluation)
- Program Learning and Training
- Communications

Each department user can view and act only on modules relevant to them (e.g., Procurement can only access procurement milestones).

---

## 🔐 Important Notes

- Access is granted at the city, state, or project level depending on your role.
- All roles follow Frappe’s Role Permission Manager rules.
- Workflows enforce who can approve, reject, or edit data.

Refer to the appropriate workflow documents to understand your responsibilities.
