# Activities Module

This module is central to tracking the lifecycle of program-related activities. Activities can be financial or non-financial.

---

## Fields

| Field | Description |
|-------|-------------|
| **Funder** | Auto-filled based on selected Project |
| **Project Name** | Linked to a Project |
| **State / City** | Place of implementation |
| **Description of Activity** | Brief summary |
| **Type of Activity** | Financial / Non-Financial |
| **Project Code** | Auto-filled |
| **Completion Month** | Month the activity is expected to complete |
| **Initiation Date** | Expected start |
| **Completion Date** | Expected end |
| **Requirements** | Any specific needs |
| **Support Department** | Department assigned |
| **Approval Status** | Auto-updated through workflow |
| **Budget Requested / Approved / Utilised** | Budget tracking fields |
| **Payment Processed** | Yes / No |
| **Status** | Current state of the activity |
| **Comments** | Remarks or escalations |

---

## 📝 User Instructions

### ✅ To Create a New Activity:
1. Go to **Activities** > **New**.
2. Select a Project. State/City will auto-load.
3. Fill the required fields – activity type, dates, budgets.
4. Assign the department responsible.
5. Save the form.
6. Submit it for approval using the activity workflow.

### ⚙️ Workflow States:
- Submit from City Manager
- Approval from State Manager
- Approval from Deputy Director
- Approval from HR/Procurement
- Finalised

Workflow transitions are handled automatically.

---

## 🛠 Notes

- Delayed activities trigger alerts.
- Approval routing depends on activity type and department.
- Monitor status changes via the dashboard or reports.
