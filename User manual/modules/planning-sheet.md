# Planning Sheet Module

The Planning Sheet module allows City Managers to prepare and submit planned activities for a project and location within a defined tenure.

---

## Fields

| Field | Description |
|-------|-------------|
| **City Manager** | Name auto-filled from login |
| **Project Name** | Linked to an existing project |
| **Project Start / End Date** | Auto-filled from project |
| **Budget Allocated** | Funds available for planning |
| **Planned Activities** | Multi-select table of activities to be included |

---

## 📝 User Instructions

### ✅ To Create a Planning Sheet:
1. Navigate to **Planning Sheet** > **New**.
2. Select the relevant Project and City.
3. Enter the allocated budget and verify dates.
4. Choose from available activities to plan.
5. Save and submit.

### ⚙️ Workflow:
- **Activity Under Completion**
- **Activity Planning Completed**

Only the **City Manager** can transition the Planning Sheet status using the **Submit** action.

---

## 🛠 Notes

- Once submitted, activities from this sheet become visible for further tracking.
- Budget utilization against these plans is monitored in the dashboard.
